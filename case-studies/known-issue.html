01 Overview

Known Issue is a name-based apparel and ecommerce concept built around predetermined records for first names rather than custom text.

Instead of allowing customers to personalize garments, Known Issue releases selected names as designed records. A single name can have multiple designs or garment types associated with it.

The main design challenge was defining the product system around the apparel: what counts as a record, how people search, how multiple products are grouped, and what happens when a name does not exist.

07 Edge cases + iteration

The model needs to account for spelling variants, duplicate subjects, record availability, sold-out variants, and names with many releases.

These are the points where archive language and commerce language can diverge, so the interface should make state changes explicit.

08 Where it landed

The concept landed on a subject-first discovery model with record-level commerce.

That separation lets the brand feel like an index while preserving a conventional path from a selected design to a purchasable variant.

09 What I’d validate next

The next questions are whether people understand “record” without explanation, whether alias behavior feels predictable, and whether requesting a name is distinct enough from customization.
