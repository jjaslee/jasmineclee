01 Overview

A photography portfolio designed around the pace, scale, and physicality of image sequences.

The experience gives each body of work room to establish its own rhythm while keeping navigation and booking close at hand.

02 Gallery behavior

Gallery rules respond to the amount and orientation of the work rather than forcing every project into one grid.

Long galleries

Sequencing and varied scale sustain movement through a larger set.

Short galleries

Smaller bodies of work retain presence without artificial repetition.

Responsive layout

Images collapse into a readable single-column order on narrow screens.

03 Interaction details

Small cues make the gallery feel tactile without competing with the images.

Hover + cursor states

Desktop states clarify which images or controls are interactive.

Mobile interaction

Tap targets and page scrolling do not depend on hover.

Tilt cue

A restrained directional cue can suggest movement without becoming decoration.

04 Booking flow

The booking path should feel distinct from browsing, but still belong to the same visual world.

Session selection

People begin with the kind of session they are looking for.

Form behavior

Questions stay focused and preserve progress as the form develops.

Validation

Errors appear next to the field that needs attention and remain keyboard accessible.

Booking flow capture — visual pending

05 Accessibility + browser behavior

The core gallery remains usable when motion, pointing precision, or browser behavior changes.

Reduced motion

Movement cues should have quiet or static fallbacks.

Contrast

Controls remain distinct from varied image tones.

iOS Safari

Viewport height and touch behavior require explicit checks.

06 Implementation

The site is structured as a responsive React interface with reusable gallery and interaction patterns.

React / Vite / Tailwind

The stack supports component reuse and direct control over responsive layout.

AI-assisted implementation

Implementation assistance supports iteration while final interaction and visual decisions stay authored and reviewed.

07 Edge cases + iteration

The difficult cases are uneven image counts, mixed orientations, very short series, slow image loading, and browser-specific touch behavior.

08 Where it landed

The portfolio became a responsive image-first experience with distinct project rhythms and a direct path to booking.
