01 Overview

The Studio Index is a curated digital archive that transforms subjective aesthetic preferences into a structured, browsable system.

The system connects discovery to action through filtering, detailed context, saved journal entries, and external retailer links.

02 Content model

A flexible schema makes aesthetic taste tangible enough to browse without flattening it into a single label.

Objects

Each item is a first-class entry with its own identity and detail view.

Metadata

Aesthetic, spatial context, function, materials, and sourcing support retrieval.

Relationships

Shared dimensions connect individual objects into explorable clusters.

03 Information architecture

The archive supports both directed filtering and open-ended discovery across dense information.

Categories

Stable dimensions give the collection navigable structure.

Context

Spatial and aesthetic context explains why an object belongs.

Discovery

Multiple entry points allow a person to browse before knowing what to call their taste.

04 Editorial + practical information

Each entry balances narrative context with the practical details needed to act on a discovery.

Story

Editorial framing describes the object’s aesthetic and contextual role.

Product information

Materials and sourcing keep the entry grounded in the object itself.

Retailer links

External links bridge research and purchasing without turning the archive into a storefront.

05 Publishing system

Reusable structures let the collection expand without redesigning every entry.

Reusable structures

Shared field patterns keep filtering and detail pages consistent.

Content workflow

Collection, normalization, review, and publishing form one repeatable pipeline.

06 Implementation

The project joins a structured backend pipeline to filtering, detailed item views, and a personal journal interface.

Sanity / Supabase

The content and data layers support normalized entries and reusable interface views.

AI-assisted workflow

Assistance can accelerate collection and normalization while curation and schema decisions remain reviewed.

07 Scale + edge cases

Scale introduces incomplete metadata, duplicate products, dead retailer links, overlapping categories, and objects that resist a single context.

08 Where it landed

The result is a scalable archive that connects data, interface, and real-world action while preserving space for subjective discovery.

09 What I’d validate next

Next, I would test whether the metadata vocabulary matches how people naturally describe objects and how well discovery holds up as the collection expands.
